# 08 — Compare original vs topology optimized (four pairs)

For each BCCZ, Cube, Fluorite Truss, Octet Truss, compare **Original vs Topo Optimized** under same Tough 2000 material, full footprint definition, loading convention, solver and mesh independence criteria. Compare mass/volume (when density known), relative density and porosity, initial stiffness, yield force, yield strength, yield strain, local stress concentration, deformation mode, mesh counts and solver warnings, performance sigma_y/rho_rel, and percent differences.

Produce four separate pair comparison reports each containing a side-by-side CAD image, equal-view contour panel, overlayed engineering curves with red yield points, matching instructor-style plots, per-case mesh convergence evidence, table of inputs, and a documented interpretation of whether optimization increased/decreased performance and why. Then create a cross-design 8-case table ranking only valid comparisons; call out if optimized design has thinner ligaments that require more mesh refinement or altered collapse mechanism. Do not presume topology optimization improves strength or weight. Distinguish local von Mises concentration from effective material response and cross-sectional area adjustments.

Generate a final executive technical report with: objective, method and assumptions, geometry audit and material XML, loading test selection, validation benchmark, convergence, individual case findings, four paired comparisons, eight-design ranking, engineering recommendations and limitations. Produce source Markdown + polished PDF if supported by local tooling; if PDF not available preserve Markdown/figures and explicitly report that limit. Provide a concise two-page FEM summary suitable for assignment milestone; full report suitable for later writeup. Screenshot gallery/thumbnail index and complete manifest are mandatory.
