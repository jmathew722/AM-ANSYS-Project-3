# 04 — Three-plus meshes; real convergence and external validation

Required **at least 3** systematically refined meshes PER CASE. Coarse/medium/fine are names, not guarantees. For example refine target edge size by factor 0.7 with sufficient elements across the smallest relevant ligament, adjusting if topology requires. Choose reasonable computational resource limits. For each refinement record target size, node count, element count, worst/median quality, model DOFs, solver runtime, success, residuals, stiffness and engineering yield stress/force when measurable. Calculate relative change between successive levels: `100*abs(q_i-q_(i-1))/abs(q_i)` with zero-safe behavior. Suggested engineering stopping threshold **<2% for BOTH effective stiffness and yield strength across the final two converged meshes**; must also inspect buckling mode and relevant field consistency. This threshold is a proposed engineering criterion, NOT assigned by instructor. If no yield, compare force at fixed displacement and stiffness; flag yield-convergence pending.

No claiming 'finest possible' mesh or 'most accurate' if converged response not established. Singular local maximum stresses are not a reliable sole metric. Improve mesh or model if mesh response is unstable, check topology changes, contact, material behavior and constraints. Save three+ meshes' screenshots, logs and CSV, plot metric vs mesh size / element count. Mark each case mesh status.

Independent verification: analytic elastic block test (EA/L) and reaction/force balance; compare **one appropriate reference design** to trustworthy published experimental/numerical data *only if same relevant geometry/material/load is available*. Old Ling et al. polymer-octet paper's grey/durable material data MUST NOT be labeled direct Tough 2000 validation. When experimental/benchmark data unavailable, report verification only and validation pending.
