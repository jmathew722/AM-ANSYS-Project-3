# 07 — Editable, professional Excel workbook for eight cases

Create Excel using Python after real simulation data extraction. Keep formula cells editable, use genuine Excel charts and freeze panes. Tabs: `Dashboard`, `Inputs_and_Source`, `Geometry_Properties`, `Material_Tough2000`, `Eight_Case_Summary`, one tab per case or a normalized `Step_History` with source CSV traceability, `Yield_Methods`, `Mesh_Convergence`, `Four_Paired_Comparisons`, `Strength_Density_Ranking`, `Validation`, `Run_Status`.

User-entered or CAD-measured cells: W,D,H (mm), Vsolid (mm³), Venv (formula), solid density (user/verified source only), measured mass (optional), unit cell count, initial/support orientation; load steps and total reaction. Formula cells: A_gross=W*D, Venv=W*D*H, rho_rel=Vsolid/Venv, porosity_pct=(1-rho_rel)*100, mass=rho_resin*Vsolid if density exists, weight_N=(mass_g/1000)*9.80665, engineering stress=F_N/A_mm2, engineering strain=delta_mm/H_mm, sigma_y=F_y/A_gross, efficiency=sigma_y/rho_rel, percent mass reduction and strength/rho changes for four original vs optimized pairs.

Separate material-yield onset (19.6405024 MPa in XML hardening), maximum local equivalent stress, and effective engineering lattice yield stress—never interchange. Define normalization, tie/invalid handling and source flags. Blank/`N/A` rather than invented values if input absent. Excel charts built on numerical rows, not pasted screenshots alone. Include four pairs side by side and an eight-case rank sorted by validated yield/relative density, clearly indicate cases missing yield or mesh convergence. Excel default formulas may need recalculation in Excel; verify formulas/reference integrity and no #REF! errors. All Excel and Python figures go under `FINALUPLAD_Folder`, not elsewhere.
